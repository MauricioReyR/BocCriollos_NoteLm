## 📐 Especificaciones de `og-image.jpg`

- **Formato:** JPEG (.jpg) — recomendado por Facebook/WhatsApp
- **Dimensiones exactas:** 1200 × 630 píxeles
- **Peso máximo:** < 8 MB (ideal < 300 KB)
- **Relación de aspecto:** 1.91:1
- **Contenido recomendado:** Foto real de tus productos (empanadas, combos, arepas) con el logo o nombre del negocio

### Consejos para la imagen
1. Usa una foto bien iluminada de tus productos más vendidos
2. Incluye el texto "Bocaditos Criollos" en la imagen
3. Evita texto demasiado pequeño (no se leerá en previsualizaciones)
4. Colores: usa los tonos del branding (burnt-red, warm-orange, cream)

## 🔄 ¿Cómo reemplazar la imagen?

1. Prepara tu foto en **1200×630px**
2. Nómbrala **`og-image.jpg`**
3. Cópiala aquí: `public/images/og-image.jpg`
4. Reemplaza el archivo existente
5. El cache-busting se hace automáticamente con `?v=timestamp`
